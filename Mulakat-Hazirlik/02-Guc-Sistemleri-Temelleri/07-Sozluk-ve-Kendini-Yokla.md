Önce [01](01-Guc-Birim-Sistem-Modeller.md).

| Kelime | Düz anlam |
| --- | --- |
| Aktif güç | İş yapan elektrik |
| Reaktif güç | Hattı dolduran, gerilimi etkileyen kısım |
| Görünür güç | İkisinin toplam doluluğu |
| Frekans | Ülke nabzı (50) |
| Gerilim | Mahalle tansiyonu |
| Fazör | Büyüklük + açı |
| Üç faz | Üç telli sistem |
| Hat gerilimi | İki tel arası |
| Per-unit | Normale bölmek |
| Ybus | Bağlantı tablosu |
| Kondansatör | Ucuz reaktif destek |
| STATCOM | Hızlı reaktif destek |
| Kademe | Trafo ayarı |
| Dyn11 | Yaygın dağıtım trafo bağlantısı |
| Bara | Hatların buluştuğu nokta |

## 5 soruluk kontrol

1. Aktif ile reaktif farkı?
2. Frekans mı yerlidir, gerilim mi?
3. Yüksek gerilim neden?
4. Per-unit ne işe yarar?
5. Reaktif neden yakında üretilir?

Cevap: (1) biri iş yapar, biri hattı doldurur (2) gerilim (3) kayıp azalsın (4) aynı dil (5) uzaktan zayıflar
