# Sözlük — “şu kelime ne?”

Önce [01 kartları](01-Guc-Birim-Sistem-Modeller.md). Bu sayfa kelime unutunca bakmak içindir.

## Sözlük

| Kelime | Düz Türkçe |
| --- | --- |
| Aktif güç (P) | İş yapan elektrik |
| Reaktif güç (Q) | İş yapmayan ama hattı dolduran, gerilimi etkileyen kısım |
| Görünür güç (S) | P ile Q’nun birlikte hattı ne kadar doldurduğu; cihaz buna göre seçilir |
| Frekans | Saniyedeki salınım; Türkiye’de 50. Üretim–tüketim dengesi |
| Gerilim | “Ne kadar itici güç”; mahalle mahalle değişir |
| Fazör | Salınan dalgayı büyüklük + açı diye iki sayıyla anlatmak |
| Slack / salınım barası | Açıyı sıfır kabul ettiğimiz referans nokta |
| Üç faz | Üç kaymalı dalga / üç tel |
| Hat gerilimi | İki faz arası (400 kV budur) |
| Faz gerilimi | Bir faz ile nötr arası |
| Per-unit | Her şeyi “normale bölüp” aynı dilde yazmak |
| Ybus | Şebekenin kim-kime-bağlı tablosu |
| Seyrek matris | Çoğu kutusu boş tablo |
| Kompanzasyon | Reaktifi yükün yanında üretmek / dengelemek |
| Kondansatör | Ucuz reaktif kaynağı |
| STATCOM | Hızlı reaktif cihazı (MAM ürün ailesi) |
| OLTC / kademe | Trafonun gerilim ayarı; reaktif üretmez |
| ZIP / yük modeli | Gerilim düşünce yükün nasıl davrandığının modeli |
| Dyn11 | Dağıtım trafosu bağlantı tipi (üçgen–yıldız) |
| Sıfır dizi / toprak yolu | Toprak arızasında üç fazın aynı yönde aktığı özel yol |
| Termik limit | Telin ısınma tavanı |
| Kararlılık limiti | Sistemin salınıp kopmama tavanı |
| Bara | Hatların bağlandığı düğüm |
| Tek hat şeması | Üç fazı tek çizgiyle gösteren sade harita |

## Mini kontrol (hesap yok)

Cevaba bakmadan kendi cümlenle yaz:

1. Aktif güç ile reaktif güç farkı nedir?
2. Frekans ile gerilimden hangisi “mahalle” göstergesidir?
3. Yüksek gerilim neden kullanılır?
4. Fazör neyi iki sayıyla anlatır?
5. 400 kV hat gerilimi midir, faz mı?
6. Per-unit ne işe yarar?
7. Ybus neyin haritasıdır?
8. Reaktif neden yakında üretilir?
9. Kondansatör ile STATCOM’u bir cümlede ayır.
10. Dyn11’de toprak arızası neden her tarafta aynı görünmez?

### Kısa cevaplar

1. Aktif iş yapar; reaktif hattı doldurur, gerilimi etkiler.
2. Gerilim.
3. Akımı küçültüp kaybı azaltmak için.
4. Büyüklük ve açı.
5. Hat gerilimidir (iki faz arası).
6. Farklı gerilimleri aynı dile getirmek.
7. Şebeke bağlantılarının.
8. Uzun yolda zayıflar; yerel gerilimi kurtaramaz.
9. Kondansatör ucuz/yavaş/zayıfken düşer; STATCOM hızlıdır.
10. Üçgen taraf toprak yolu akımını diğer tarafa geçirmez.
