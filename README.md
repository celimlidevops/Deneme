# TÜBİTAK MAM mülakat hazırlığı

Elektrik iletim ve dağıtım şebekeleri için analiz ve yazılım mülakat notları. Kişisel özgeçmiş, proje adı ve kullanıcı yolu içermez. Köşeli parantezler doldurulacak yerlerdir.

## Yayında açmak

GitHub Pages kaynağını ana dalın kökü yap. Site `index.html` ile notlara gider.

Doğrudan klasörden de açılır: `Mulakat-Hazirlik/index.html`.

Sorular `Mulakat-Hazirlik/test.html` adresindedir. Her sayfanın soruları `Mulakat-Hazirlik/sorular/` altındaki JSON dosyasındadır.

## Bilgisayarda açmak

`Notlari-Ac.bat` yerel sunucuyu başlatır ve aynı Wi-Fi adresini yazar.
